# Conversor de divisas en Python

Este es un pequeño proyecto hecho en Python que permite convertir pesos argentinos a distintas monedas como dólar, euro y real brasileño.

El usuario ingresa la cantidad de dinero que desea cambiar y luego selecciona la moneda de destino. El programa realiza la conversión usando cotizaciones fijas y muestra el resultado en pantalla.

## Cómo funciona
- Se ingresa una cantidad de dinero en pesos.
- Se elige la moneda a la que se quiere convertir.
- El programa calcula la conversión automáticamente.
- Se muestra el resultado final.

## Monedas disponibles
- Dólar
- Euro
- Real brasileño

## Tecnologías usadas
- Python
- Condicionales (if / elif / else)
- Bucles (for)
- Entrada de datos (input)
- Operaciones matemáticas básicas

## Ejemplo de uso
Cantidad a cambiar: 50000  
Cambio que desea: dolar  
Su vuelto sería: 35.74
